# Maestros (no incluidos en el repo)

Se suben a mano al Volume `ppto27/90_maestros/`. No se versionan porque contienen datos internos.

| Archivo | Contenido |
|---|---|
| `maestros_ppto27.xlsx` | Plantillas esperadas, CeCos, cuentas, proveedores, Formato Perú, tipo de cambio 2027 |
| `alias_ppto27.xlsx` | Alias aprobados (plantillas, cuentas, proveedores) que llena Planeamiento |
| `drivers_ppto27.xlsx` | Drivers de reparto Dir/Ind por país × CeCo × vehículo |

Se regeneran con `herramientas/generar_maestros.py` desde los insumos del proyecto.
